# KD AI CITY

Стартовый каркас виртуальной штаб-квартиры с интерактивным 3D-городом, панелью управления и серверным AI Director.

## Локальный запуск

Требуется Node.js 20.9+.

```bash
npm install
cp .env.example .env.local
# Заполни OPENAI_API_KEY и KD_AI_CITY_ACCESS_KEY в .env.local
npm run dev
```

Открой http://localhost:3000.

## Переменные окружения

- `OPENAI_API_KEY` — секретный ключ OpenAI, используется только на сервере.
- `KD_AI_CITY_ACCESS_KEY` — отдельный длинный случайный ключ владельца для защиты API поручений.

Сгенерировать ключ доступа можно командой:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Добавь обе переменные в локальный `.env.local` и в Vercel Environment Variables. Не используй префикс `NEXT_PUBLIC_`, не добавляй реальные значения в GitHub и не отправляй их в переписку. В интерфейсе ключ владельца вводится вручную и не сохраняется после перезагрузки вкладки.

## Проверка доступности

После развёртывания открой `/api/health`. Endpoint возвращает статус приложения, название сервиса, версию и время ответа. Это проверка доступности Next.js, а не проверка подключения OpenAI или работоспособности AI Director.

## Состав первого этапа

- Интерактивная 3D-панорама города на React Three Fiber.
- Панель шести отделов/ролей.
- Центр поручений и журнал событий текущей вкладки.
- Серверный endpoint `/api/agents/run` с AI Director и пятью профильными агентами как инструментами.

## Безопасность и ограничения MVP

- API поручений закрыт, если `KD_AI_CITY_ACCESS_KEY` не задан или не совпадает.
- Проверка ключа выполняется на сервере с constant-time сравнением.
- Размер тела запроса ограничен 8 КБ, длина задачи — 4 000 символов.
- Общий ключ владельца — временная защита для одного владельца, а не полноценная система аккаунтов. Перед публичным использованием добавь полноценную авторизацию, лимиты запросов и аудит.
- Внешние публикации, финансовые операции и destructive-действия должны требовать явного подтверждения владельца.
- История пока хранится только в состоянии страницы. Supabase, постоянная память, фоновые очереди и live-события — следующие этапы.
- Не добавляй секреты в `NEXT_PUBLIC_*` и не коммить `.env.local`.
