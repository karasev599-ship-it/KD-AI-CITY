# KD AI CITY

Стартовый каркас виртуальной штаб-квартиры с интерактивным 3D-городом, панелью управления и серверным AI Director.

## Локальный запуск

Требуется Node.js 20.9+.

```bash
npm install
cp .env.example .env.local
# Добавь OPENAI_API_KEY в .env.local
npm run dev
```

Открой http://localhost:3000.

## Состав первого этапа

- Интерактивная 3D-панорама города на React Three Fiber.
- Панель шести отделов/ролей.
- Центр поручений и журнал событий в интерфейсе.
- Серверный endpoint `/api/agents/run` с первым AI Director на OpenAI Agents SDK.

## Честный статус

Сейчас только AI Director подключён как реальный серверный агент. Остальные роли пока представлены интерфейсом и не выполняют самостоятельные задачи. История пока хранится только в состоянии страницы. Счётчики демонстрационные. Supabase, авторизация, постоянная память, отдельные инструменты агентов, фоновые очереди и live-события — следующие этапы.

## Безопасность

- Никогда не добавляй секреты в `NEXT_PUBLIC_*` и не коммить `.env.local`.
- Внешние публикации, финансовые операции и destructive-действия должны требовать явного подтверждения владельца.
- Перед production-запуском добавить авторизацию, RLS, лимиты расходов и аудит действий.
